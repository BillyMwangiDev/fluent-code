# Product

## Register

product

## Users

Developers who run Claude Code and/or Codex (OpenRouter as a Claude Code compatibility preset)
and want to operate multiple concurrent terminal sessions, credentials, and coordinating agents
from one desktop surface instead of juggling raw CLIs across terminal tabs.

## Product Purpose

Fluent Code orchestrates real, unmodified coding-agent CLI processes — credentials, concurrency,
and cross-agent coordination — without ever re-implementing what happens inside an agent turn.
Success looks like a developer trusting it to run several agent lanes on the same project at once,
with visible file claims/conflicts/handoffs, safe credential fallback across subscription/platform
credits/API key, and clear hardware/token headroom, all through a dense, terminal-native interface.

## Brand Personality

Plain, practical, and encouraging — a developer terminal tool, not a consumer chat app. Avoid hype
("revolutionary," "seamless," "10x"). Dense information design (compact cards, terminal panes,
tables, sparklines, line/area charts) over decorative UI.

## Anti-references

Chat bubbles, oversized illustrations, consumer-chat visual language. Progress bars as the default
way to show usage/health (favor graphs). Coral (the one accent/alert color) used for large fields
or ordinary data series instead of actions/anomalies only.

## Design Principles

- Dense but organized: pack real information without letting sections crowd or overlap.
- Provider and account context stays explicit wherever sessions appear.
- Coordination is inspectable, not hidden: show claims, conflicts, handoffs, decisions.
- Graph-first observability: sparklines/line/area charts over bare numbers or progress bars.
- Consistent, premium spacing end-to-end — one shared rhythm, not per-page improvisation.

## Accessibility & Inclusion

Standard WCAG AA: sufficient contrast in every theme bundle, full keyboard navigation, visible
focus states, and a reduced-motion alternative for any animation.
